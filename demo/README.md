# Influencer Takip Demo

Bu dizinde `node scripts/build.mjs` komutunu çalıştır. Worker giriş dosyası `dist/server/index.js`. Canlı kayıtlar için sunucu tarafında `SOURCE_SITE_ACCESS` ve `SHARED_PANEL_KEY`, oturum imzalama için güçlü bir `EDITOR_PASSWORD` ve giriş için `PANEL_PASSWORD` gizli değişkenlerini tanımla. `PANEL_USERNAME` varsayılan olarak `admin` olur. Ana panelde marka migrasyonunu uygula.
